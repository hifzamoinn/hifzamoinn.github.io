# Hifza Moin — GitHub Pages Portfolio

Standalone static HTML/CSS portfolio with Apple-inspired frosted glass styling.

## Deploy
1. Create a new GitHub repository, ideally `<username>.github.io`.
2. Upload the **contents** of this folder to the repository root.
3. In Settings → Pages, choose Deploy from a branch, `main`, root.
4. Open the resulting GitHub Pages URL.

## Files
- `index.html` — landing page
- `styles.css` — glass style and responsive layout
- `projects/` — three technical approach pages

## Review before publication
- Confirm official job title, career years, employer history, professional summary and project-specific contributions against Hifza's CV.
- Five client roles are supplied by the requester. The site does not publish confidential screenshots or claim client-specific results.
- Planning and Datasphere project pages describe representative solution architectures, not verified client deliverables.
- No stock or client images are required.
- Fonts are loaded from Google Fonts; the page has system-font fallbacks.
